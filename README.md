# Zebra Verde — Website (preliminary)

Luxury e-commerce home page for **zebraverde.com**, in English, built in plain HTML/CSS/JS.

| Version | File |
|---|---|
| Dark (deep emerald) | `index.html` |
| White background | `white.html` |

Both files share the same code; the only difference is the `data-theme` attribute on `<html>` (`dark` / `light`).
Images live in `assets/` (WebP).

Pending: real product names and prices (`[PRICE]`), leather and finish details, and connecting the bag, account and newsletter to the store back-end.
